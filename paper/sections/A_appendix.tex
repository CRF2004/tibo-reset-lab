\section{Appendix: Reproducibility Details}

The repository retains raw source indices, bilingual evidence summaries, annotation instructions,
adjudication records, daily and six-hour person-period tables, context snapshots, rolling forecasts,
locked prospective manifests, automation logs, exclusions, and revisions. All timestamps use UTC.
The frozen protocol has SHA-256
\texttt{de216beb5dbbf1dbc77ae863f2628b1d750c55f9c7e52f6efed93b0b39d949cb}.

The historical six-hour comparison starts only after 120 valid prior periods and at least two
examples of each class. Binary features pass through preprocessing; continuous and cyclic features
are standardized using training-window statistics. The paired bootstrap resamples contiguous
seven-day blocks to preserve short-range dependence.
